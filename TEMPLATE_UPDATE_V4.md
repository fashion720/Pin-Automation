# Pinterest Template Polish v4

This revision keeps the approved 14-template visual system and only applies final polish:

- All built-in template CTAs are Pinterest/blogging-oriented (discover more ideas, explore more ideas, view more ideas, etc.). No shopping-focused CTA remains in built-in templates.
- CTA buttons are larger and use stronger typography.
- CTA text color is automatically chosen for contrast against the button background.
- Footer/website branding is rendered as a centered rounded badge with a background color, readable contrast, and dynamic width based on the actual brand text.
- Footer colors rotate through a broader editorial palette rather than always appearing black/white.
- CTA vertical placement is kept above the website badge to prevent overlap.
- Existing image-slot geometry and approved template composition are preserved.
